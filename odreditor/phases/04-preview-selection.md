# Phase 04 Preview and selection

Status: planned. Dependencies: phases 01 to 03.

## Deliverable

Selectable map geometry generated by libOpenDRIVE, with local diagnostics and safe rebuilds.

## Work

1. Implement OdrAdapter as the only direct model integration surface.
2. Build road-level native projections from XML snapshots.
3. Reconstruct cached curves and lane borders after relevant document changes.
4. Extract separate lane, marking, object, signal, and reference-line parts.
5. Associate preview/picking data with source NodeIds.
6. Implement top-down/perspective cameras, render-origin handling, selection overlays, and frame selection.
7. Add dirty-road scheduling and revision checks.
8. Map parse/geometry diagnostics to the document tree.

## Failure behavior

- Preserve XML even when native parsing rejects a road.
- Show independent reference-line geometry where it is evaluable.
- Keep unaffected roads visible and editable.
- Hide invalid surfaces or explicitly mark retained previews stale.
- Avoid preview field mutation that bypasses constructor caches.
- Convert diagnostics before their native/XML owners are destroyed.
- Catch supported native exceptions at the integration boundary.

## Acceptance

- Selecting a mesh selects the same element as the tree.
- Width and spiral parameter changes affect fresh geometry.
- Repeated edits do not retain dangling model handles or GPU resources.
- Duplicate or unsupported source content remains accessible in the document.
- Regeneration does not write defaults or normalized coefficients back into XML.
- Editing one road does not rebuild all unrelated roads.

## Verification

Keep a small adapter integration family for cache reconstruction, ownership, source association, and rejected input.
Use known geometric results rather than comparing the adapter with itself.
Use temporary browser checks for camera/picking behavior and visual quality.

## Performance decision

Measure realistic files here. Start with scheduled rebuilds and cheap drag previews.
If a native call causes unacceptable interaction stalls, add an isolated preview worker with embedded payload and revision-tagged results; retain the single HTML contract.
