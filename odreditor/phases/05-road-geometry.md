# Phase 05 Road geometry tools

Status: planned. Dependencies: phases 02 to 04.

## Deliverable

Create and edit roads with line, arc, spiral, and ParamPoly3 geometry.

## Tools

| Tool | Inputs | Result |
| --- | --- | --- |
| Line | Start plus endpoint, or heading/length | Segment pose and length. |
| Arc | Start pose plus curvature/radius and length/sweep | Circular segment and sampled preview. |
| Spiral | Start pose, length, start/end curvature | Clothoid segment and sampled preview. |
| ParamPoly3 | Coefficients or control handles | Cubic parameters, consistent length, declared pRange. |
| Road template | Initial geometry, ID, selected lane defaults | New road subtree in one transaction. |
| Chain edit | Selected insertion/deletion/order | Stations and length for that selected chain. |

## Work

1. Add compact tool controls and shared numeric fields.
2. Implement temporary gesture state and cancellation.
3. Call geometry evaluators directly from C++ for live previews.
4. Convert control handles and curve parameters using explicit coordinate conventions.
5. Serialize generated parameters into XML with sufficient precision.
6. Add optional snapping to existing endpoints and chosen tangent direction.
7. Commit all generated nodes/attributes as one edit.

## Behavior

- Snapping positions geometry; links are created by the explicit connection tool.
- Existing connected roads remain fixed.
- Appending a segment deliberately starts it at the chosen endpoint.
- Editing an independent segment does not silently move later segments.
- Reject non-finite/degenerate tool candidates before calling unsafe native calculations.
- Represent zero-curvature/equal-curvature cases with the appropriate line/arc construction when generating geometry.
- Never serialize normalized native ParamPoly3 coefficients with an incompatible original pRange.

## Acceptance

- Add Road -> choose endpoint -> draw -> save/reopen works for each supported type.
- Numeric and graphical edits use the same command path.
- Escape cancels; release creates one undo entry.
- Road and segment lengths generated by a drawing operation agree within documented tolerance.
- Unsupported raw geometry remains preserved.

## Verification

Keep algorithm cases for line/arc endpoints, polynomial conversion/length, and spiral limiting cases.
Use independently specified coordinates or invariants.
Reuse document and adapter integrations; temporary browser checks cover gestures.

## Later work

Endpoint-constrained spiral fitting and automatic alignment of existing chains belong to phase 07.
